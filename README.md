# Unit Converter (Java)

A Java console application that converts:
- Length (meter, km, cm, mile, feet)
- Weight (kg, pound)
- Temperature (Celsius, Fahrenheit, Kelvin)

## Features
- Menu-based system
- Bi-directional conversions
- Clean and modular code

## How to run
1. Compile: `javac Main.java`
2. Run: `java Main`
